Propuesta de Interfaz – Registro de Usuarios
Objetivo

Diseñar una interfaz moderna, institucional, segura y fácil de utilizar para registrar y administrar los usuarios del Sistema de Gestión Documental.

Diseño

La interfaz tendrá un estilo empresarial y minimalista, utilizando colores corporativos, fondos claros, paneles organizados, bordes redondeados, sombras suaves, iconos intuitivos y diseño responsive. Los efectos de transparencia serán moderados para mantener una buena legibilidad.

Registro de usuario 

El formulario estará dividido en secciones:

Datos personales: nombres, apellidos, DNI, fecha de nacimiento, correo y teléfono.

Lugar de nacimiento: región, provincia y distrito mediante listas dependientes.

Domicilio actual: región, provincia, distrito, dirección y referencia.

Información laboral: área, cargo y sede u oficina.

Datos de acceso: nombre de usuario, contraseña, confirmación de contraseña y estado de la cuenta.

Rol: Administrador, Mesa de Partes, Operador o Auditor.

Validaciones

El sistema verificará campos obligatorios, DNI, correo, usuario y correo no duplicados, coincidencia de contraseñas y selección correcta de ubicación.

Los errores se mostrarán directamente en el campo correspondiente.

Acciones

El formulario contará con:

Guardar: registra el usuario.
Limpiar: elimina los datos ingresados.
Cancelar: regresa al listado.

Después de guardar correctamente, se mostrará una confirmación del registro.

Listado de usuarios

Se mostrará una tabla con nombre, DNI, usuario, área, cargo, sede, rol, estado y fecha de registro.

El listado contará con búsqueda y filtros por nombre, DNI, área, rol y estado.

Desde el listado se podrá consultar, editar, activar o desactivar usuarios, según los permisos asignados.

Seguridad

El acceso a la administración de usuarios estará controlado mediante roles y permisos. Las contraseñas deberán almacenarse de forma segura y nunca mostrarse directamente.

Flujo

Registro → Datos personales → Ubicación → Domicilio → Información laboral → Acceso → Rol → Validación → Guardar → Confirmación.

Criterio general

La interfaz busca ser profesional, clara, segura y práctica, manteniendo una estructura visual consistente con el resto del Sistema de Gestión Documental.
