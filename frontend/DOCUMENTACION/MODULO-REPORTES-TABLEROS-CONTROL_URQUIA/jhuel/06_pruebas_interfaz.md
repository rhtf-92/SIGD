# 06. Pruebas de Interfaz - Carga de Gráficos y Métricas

## Casos de Prueba para el Dashboard
* **Prueba de Carga de Gráficos:** Verificar que los componentes visuales rendericen correctamente los datos de *tiempo promedio de respuesta* al cambiar los filtros de fechas.
* **Prueba de Responsividad:** Comprobar que las tarjetas de KPIs y las tablas de *cuellos de botella* se reorganicen de manera fluida al cambiar la resolución de pantalla (simulando dispositivos móviles y tablets).
* **Prueba de Umbrales de Alerta:** Validar que si una oficina supera el tiempo límite configurado, el indicador visual de la interfaz cambie automáticamente a color de alerta crítica.
