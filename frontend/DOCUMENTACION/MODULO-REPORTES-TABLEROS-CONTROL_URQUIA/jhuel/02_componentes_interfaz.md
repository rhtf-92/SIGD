# 02. Componentes de Interfaz - Gráficos, Cards y Tablas

## Tarjetas de Métricas (KPI Cards)
* **KPI de Tiempo Promedio de Respuesta:** Tarjeta resumen que muestra el promedio general de días u horas que toma resolver un trámite, con indicadores visuales de tendencia (subida/bajada respecto al mes anterior).
* **KPI de Alerta de Cuellos de Botella:** Tarjeta de conteo crítico que resalta cuántas oficinas superan el límite de tolerancia de días en trámite.

## Componentes Gráficos (Charts)
* **Gráfico de Líneas o Barras:** Muestra el *Tiempo promedio de respuesta por área o funcionario*, permitiendo comparar el rendimiento operativo entre distintas dependencias.
* **Gráfico de Dispersión / Barras Horizontales:** Utilizado para la *Identificación de oficinas donde se acumulan o retrasan los trámites*, ordenando de mayor a menor retención de documentos.

## Tablas de Datos
* **Tabla Detallada de Trámites Retrasados:** Listado interactivo con columnas para: ID de Oficina, Funcionario Responsable, Cantidad de Trámites Estancados y Tiempo Máximo de Espera actual.
