# Componentes de Interfaz

## Objetivo

Definir los principales elementos visuales utilizados en el sistema.

## Componentes

* **Navbar:** acceso a opciones principales.
* **Sidebar:** navegación entre módulos.
* **Cards:** muestran información resumida.
* **Tablas:** presentan información organizada.
* **Botones:** permiten ejecutar acciones.
* **Formularios:** permiten ingresar y modificar datos.
* **Alertas:** muestran mensajes y notificaciones.

Los componentes mantienen un diseño uniforme para facilitar su uso.
