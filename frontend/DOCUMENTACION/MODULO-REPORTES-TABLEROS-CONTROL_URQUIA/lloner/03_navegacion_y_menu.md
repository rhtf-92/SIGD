# Navegación y Menú

## Objetivo

Facilitar el acceso rápido a las diferentes funcionalidades del sistema.

## Menú principal

El sistema cuenta con un menú lateral que permite acceder a:

* Dashboard.
* Usuarios/Clientes.
* Reportes.
* Estadísticas.
* Configuración.

La navegación debe ser sencilla, clara y mantener al usuario ubicado dentro del sistema.
