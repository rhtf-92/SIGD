# Validaciones Frontend

## Objetivo

Verificar los datos ingresados por el usuario antes de enviarlos al servidor.

## Validaciones

* Campos obligatorios.
* Formato correcto de correo electrónico.
* Cantidad máxima y mínima de caracteres.
* Validación de números y fechas.
* Mensajes de error claros.
* Prevención del envío de formularios incompletos.

Las validaciones mejoran la experiencia del usuario y reducen errores de ingreso.
