# Diseño UX y Responsive

## Objetivo

Diseñar una interfaz clara, moderna y fácil de utilizar.

## Diseño UX

* Interfaz sencilla e intuitiva.
* Información organizada por secciones.
* Uso de botones, iconos y colores fáciles de identificar.
* Diseño consistente en todas las pantallas.

## Diseño Responsive

La interfaz se adapta a diferentes dispositivos:

* 💻 Computadoras.
* 📱 Celulares.
* 📲 Tablets.

Se utilizan estructuras flexibles para mantener una correcta visualización en diferentes tamaños de pantalla.
