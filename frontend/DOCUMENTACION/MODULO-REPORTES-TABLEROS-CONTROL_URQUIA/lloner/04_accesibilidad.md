# Accesibilidad

## Objetivo

Permitir que la interfaz pueda ser utilizada por la mayor cantidad de usuarios posible.

## Consideraciones

* Contraste adecuado entre texto y fondo.
* Tamaños de texto legibles.
* Botones claramente identificados.
* Uso de etiquetas en formularios.
* Imágenes con texto alternativo.
* Navegación comprensible.

Se busca que la interfaz sea fácil de entender y utilizar.
